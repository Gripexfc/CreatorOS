# S3 返工：可继续、可编辑、可追溯的内容工作流

2026-09-30。此前 S3 的测试只证明模板和接口通路，不满足实际操作验收，撤回“S3 完成”的完整产品结论。

## 本次范围

实际缺口位于前端导航/工作台与后端修订服务：刷新丢失任务选择、没有正文编辑器、按钮追加固定句冒充修改、简报确认与生成合并、只有 JSON 查看、无历史修订读取入口。

本轮只返工这个垂直切片。前端拆分为应用导航、画像编辑、任务/内容库、平台编辑与预览、记忆审核；服务增加简报修订、正文基线冲突、历史读取、记忆决策日志。保留原 SQLite 表和数据。不扩到热点采集、账号导入、真实 LLM、图片或发布。

验收：从页面建立完整画像→创建任务→编辑并确认简报→创建明确标注的模板→实际修改某平台正文→保存新版本→刷新/内容库重开→查看原文与修改差异→编辑/采纳/拒绝/撤销记忆。无 AI 接入时明确显示模板模式。

## 修改边界

- `web/frontend/src/App.tsx`、页面组件和样式：可切换导航、真实编辑与回读、中文状态和错误恢复。
- `creatoros/domain/content.py`、`services/content_service.py`、`api/app.py`：上述动作的契约/事务/路由，复用现有表。
- 测试与文档：以用户动作和持久化验收，不能用字段存在替代功能验收。

验证结果：后端 `8 passed`；前端 `2 passed`、TypeScript typecheck 通过、Vite build 通过。浏览器验收覆盖总览、画像、内容工作台、内容库、能力记忆和设置页；热点与账号分析明确显示“未接入”，没有用假数据填充。当前 S3 仍使用本地确定性模板，不声称接入真实 LLM、图片生成或视频渲染。

回滚方式：停止本地服务后，将 `/tmp/creatoros-before-s3-usability.tar.gz` 解压到独立临时目录比对；数据库备份为 `/tmp/creatoros-before-s3-usability.sqlite3`。不要覆盖 `ContentPilot` 或 `.easel`，也不要把本地数据库备份提交进仓库。
