# Easel 三平台界面恢复记录

日期：2026-10-01

本轮把界面基准切回官方 [ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel)，按 Easel 工作台的发现、策划、创作、发布、归因主链路重新组织 CreatorOS。只保留公众号、小红书、抖音三个平台，其他平台不进入导航、选择器和发布卡片。

## 页面和流程

- **工作台**：显示当前任务、待核验来源、草稿与账号状态，从一个主题继续工作。
- **一键工作流**：输入主题或素材，依次完成研究简报、选题确认、三平台模板草稿和分平台编辑。
- **对话**：保留 Easel 的协作入口；没有真实 LLM 时只显示未配置状态，不伪造研究结论或高质量成稿。
- **热点雷达 / 选题库**：进入页面自动读取公开热榜，支持刷新、收藏和直接进入工作流；保存来源、记录事实状态和读者相关性，未核验线索不会被标成事实。
- **内容库**：回看任务、简报、平台版本、修改历史和来源链路。
- **发布中心**：按平台预览标题、正文、标签和媒体要求；公众号保留草稿箱动作，小红书和抖音显示连接状态与待执行动作。
- **账号**：分别查看三个平台连接器状态。Mock 连接器只验证本地状态机，真实登录需要用户完成账号授权。
- **画像**：维护创作者定位、受众、表达偏好和三个平台的适配信息。

## 真实能力边界

本地模板可以帮助走通流程，但不等于真实 LLM 成稿。研究采集、图片/视频生成、平台登录和发布只有在相应适配器返回证据后才显示成功；未接入时明确显示“待接入”“待核验”或“未连接”。界面不使用“高质量成稿”“自动变强”或类似承诺。

公众号、小红书、抖音使用各自平台字段和预览，不把公众号正文直接复制到另外两个平台。三份内容共用任务和简报的来源链路，但可以独立修改、导出和回看版本。
