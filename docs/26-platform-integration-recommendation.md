# 三平台账号数据接入建议

检查日期：2026-10-01

## 结论

CreatorOS 不应给三个平台使用同一种读取方式：

| 平台 | 推荐接入 | 当前项目方式 | 结论 |
|---|---|---|---|
| 公众号 | 微信官方数据接口（access_token + IP 白名单） | Playwright 打开公众号后台并捕获 XHR | 应优先替换为官方 API；浏览器读取只保留人工触发的兼容兜底 |
| 抖音 | 抖音开放平台 OAuth + OpenAPI | Playwright 读取创作者中心 | 应改为官方授权 API；申请 `video.data`、作品/用户数据权限 |
| 小红书 | 手动导出 CSV/JSON，本地分析 | Playwright 读取创作者中心（迁入能力） | 当前首选手动导入；官方开放平台暂未开放内容/表现数据权限 |

## 公众号

公众号官方数据接口覆盖图文群发每日数据、图文总数据、图文阅读、分享转发和用户增减等维度。接口需要公众号授权、`access_token` 和 IP 白名单；查询结果应本地缓存，避免重复请求。

当前代码的 `WeChatBrowserAdapter` 通过登录后台网页并拦截 `appmsgpublish`、`get_article_stat_tendency` 响应获取数据。这种方式依赖页面结构和登录态，改版、验证码或风控都会影响稳定性。它不应作为定时后台同步的主路径。

推荐：每日低频拉取前一日数据，失败时保留上次成功快照并显示数据日期，不重试轰炸。

## 抖音

抖音开放平台提供 OAuth 授权和数据 OpenAPI。官方文档说明，查询特定视频数据需要用户授权和 `video.data` 权限，可返回播放、点赞、评论、分享等数据；用户视频情况和粉丝数据需要申请相应数据权限，部分数据按 T+1 刷新。

当前代码的 `account_stats.py` 使用 Playwright 打开 `creator.douyin.com` 并解析页面文本。它适合临时人工读取，不适合产品默认同步。推荐改为：

1. 用户在 CreatorOS 里发起抖音 OAuth 授权。
2. 服务端保存加密后的 access token / refresh token，不保存密码和 Cookie。
3. 按授权范围读取作品数据和账号数据。
4. 按平台返回的刷新周期同步，不把“当天没有数据”判定为 0。

## 小红书

小红书开放平台当前首期开放范围是 `basic_info`。官方 Scope 文档把 `user_profile`（粉丝数、关注数、笔记数）、`read_notes`、`write_notes` 和 `read_followers` 列为规划中或需要额外审核的能力。

因此目前不能把小红书创作者中心的浏览器抓取包装成稳定的官方接入。推荐保留 CSV/JSON 导入，字段继续支持阅读/曝光、点赞、评论、收藏、分享、涨粉等。浏览器自动读取不作为默认功能，也不做定时任务。

## 产品层的统一策略

- 数据接入和内容发布分开：读取数据不会自动发布内容。
- 每个平台保存 `source_type`、授权范围、观察时间、数据日期和原始来源。
- 官方 API 优先；没有官方数据权限时使用人工导出。
- 浏览器读取必须是用户主动点击、低频、可停止，并显示“非官方 API，可能因平台改版或风控失败”。
- 读取失败、字段缺失、T+1 尚未刷新都保留为 `unknown`，不能写成 0。
- 只有达到重复样本阈值的账号内部模式，才生成候选优化经验；经验仍需用户确认后才进入画像或下一次生成。

## 实施顺序

1. 公众号官方数据 API：收益最高、指标最完整，先替换现有浏览器统计读取。
2. 抖音 OAuth/OpenAPI：申请数据权限后接入作品数据和 T+1 账号数据。
3. 小红书导入体验：优化模板、字段映射和导入校验，等待官方数据权限开放。
4. 最后再考虑浏览器兼容读取，默认关闭，不作为自动化同步方案。

## 人工导入操作清单

这套路径用于官方数据接口还没有覆盖的阶段。每个平台都先在自己的后台导出文件，再回到 CreatorOS 的“账号分析”页导入；CreatorOS 不要求用户粘贴密码、Cookie 或 AppSecret。

### 公众号

1. 登录 `mp.weixin.qq.com`，打开“数据统计 / 内容分析”。
2. 选择要复盘的日期范围，导出图文阅读、分享、收藏、评论等数据。
3. 在 CreatorOS 的“账号分析”页，把“平台”选为“公众号”，上传 CSV/JSON。
4. 把“观察时间”改成导出数据对应的日期，点击“导入并更新分析”。

### 小红书

1. 登录 `creator.xiaohongshu.com`，打开“数据中心 / 内容分析”。
2. 选择日期和笔记范围，导出阅读、点赞、收藏、评论等数据。
3. 在 CreatorOS 的“账号分析”页选择“小红书”，上传 CSV/JSON。
4. 检查标题、日期和指标映射后，点击“导入并更新分析”。

### 抖音

1. 登录 `creator.douyin.com`，打开“数据中心 / 作品分析”。
2. 选择日期和作品范围，导出播放、完播、点赞、评论等数据。
3. 在 CreatorOS 的“账号分析”页选择“抖音”，上传 CSV/JSON。
4. 检查标题、日期和指标映射后，点击“导入并更新分析”。

平台后台的菜单名称可能随改版略有变化。导入完成后，先在“可解释摘要”确认样本数量和数据日期，再查看“候选优化经验”；缺失值会保留为空，不会自动补成 0。
