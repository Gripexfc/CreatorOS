# 平台爆款拆解设计

检查日期：2026-10-05

## 参考实现

参考 Git 项目的 `BreakdownPage` 支持粘贴一条对标内容，输出一句话概括、钩子、结构、传播原因、可复制模板和 3 个结合画像的新选题。CreatorOS 复用这个交互目标，但把拆解维度按公众号、小红书、抖音分开，避免把同一套“爆款规律”套到所有平台。

## 当前入口

侧边栏进入“拆解爆款”，依次完成：

1. 选择公众号、小红书或抖音。
2. 选择粘贴正文或网页链接。
3. 粘贴参考文章、笔记、口播稿或链接。
4. 可选勾选“结合我的画像生成原创角度”。画像只发送平台定位、读者和语气，不发送参考作者身份。
5. 点击“拆解这条内容”。
6. 点击“生成平台二次创作”，在同一页面编辑我的版本。
7. 复制、下载，或点击“带入内容工作区”继续修改并保存到内容库。

## 平台拆解维度

| 平台 | 重点观察 |
| --- | --- |
| 公众号 | 标题承诺、开头留人、论证结构、事实与观点比例、阅读节奏、结尾转发理由 |
| 小红书 | 封面和标题、前两行、卡片信息密度、收藏价值、评论问题、话题标签 |
| 抖音 | 前三秒钩子、口播节奏、镜头信息、完播节点、情绪变化、评论引导 |

## 原创边界

拆解输出只提取结构、决策规则和选题机会，不逐句复述参考文本。没有公开数据时写“无公开数据”，不会补写阅读量、点赞量、收藏量或完播率。参考作者的经历、案例和表达习惯不会自动写成用户经历或用户画像。

网页链接能否读取取决于当前模型网关和来源访问权限。访问失败时结果必须标记“来源未读取”，用户可以改为直接粘贴正文。

二次创作保留参考内容的主题、核心事实、信息层级、段落数量和大致篇幅，只做必要的顺序微调；标题、开头、表达、段落句式、案例/数据归属和结尾必须重写。禁止逐句改词、拼接原句或把参考作者经历写成用户经历。生成结果是本地可编辑草稿，仍需补充用户自己的来源和案例，并完成人工事实、真人表达与平台规则审校。

## 采用的参考 Skills

- `skill-competitor-analysis`：竞品内容策略、爆款规律、互动模式和差异化机会。
- `skill-xhs-analyzer`：小红书笔记、创作者和互动信号分析；读取时必须遵守其节流规则。
- `skill-news-intelligence` / `skill-trending-topics`：补充行业文章和热点背景。
- `skill-article-outline`：分析搜索结果的标题结构、段落层级、FAQ 和内容空白。
- `skill-content-repurposing`：把已确认的原创主稿改编成其他平台版本。
- `text-polisher`、`skill-quality-gate`、`skill-persona-check`：去 AI 味、质量检查和画像一致性。

## 2026-10-01 实走验证

- 前端实际打开 `#/breakdown`，公众号、小红书、抖音三种平台按钮均可切换，正文粘贴和网页链接两种输入模式均可切换。
- 粘贴示例内容后，提交按钮从禁用变为可用；提交后页面显示 `NOT CONFIGURED：模型网关未配置或离线`，没有生成虚假的拆解结果。
- 后端 `/api/v1/status` 返回 200；`/api/skills` 返回 114 个技能并包含 `skill-competitor-analysis`；真实调用 `/api/skill` 返回 HTTP 503，和页面阻断提示一致。
- 模型设置接口实测返回 200；当前状态明确为 `configured=false`、`gatewayOnline=false`、`configExists=false`，并报告 CreatorOS 隔离 profile `creatoros` 及实际网关地址，不把本地服务在线误判为模型在线。
- 前端 `typecheck`、4 个测试用例和生产构建均通过。

当前与参考 Git 项目的差异：拆解结果和二次创作草稿会保存在浏览器本机，并可带入内容工作区；尚未自动写入热点/选题库。小红书账号数据读取也还没有接到 `skill-xhs-analyzer` 的真实数据源。模型网关配置后，下一步应先验证一条真实参考内容的字段完整性，再补结果持久化和平台数据源。

## 模型配置入口

CreatorOS 现在提供独立的“模型设置”入口，首屏只配置文本生成通道：

1. 选择 OpenAI 兼容接口、Anthropic、中转/代理或自定义兼容服务。
2. 填写模型名称、Base URL 和 API Key；已保存的 Key 只显示脱敏结果，留空表示沿用。
3. 保存后点击“连接性自测”，先验证 `/models` 可访问，再回到拆解或创作页面验证真实生成。

这样比把图片、视频、配音等六类模型一次性塞到首屏更容易上手。模型设置页只负责本机配置和自测，不把密钥写入前端代码、内容草稿或日志；CreatorOS 使用 `creatoros` profile 和 `runtime/openclaw` 隔离目录，本地 OpenClaw 网关仍需单独启动，页面会把“模型可连接”和“本地服务在线”分开显示。
