## 改造前

| 维度 | 现状 | 处理决定 |
| --- | --- | --- |
| 主题 | 温暖纸张、米白面板、森林绿和金色混用 | 统一为 Night Studio / Signal Lab |

| 状态 | 空、错、加载状态样式分散 | 统一骨架、空状态、内联错误、成功和焦点状态 |

## 信息架构保留

- 发现热点、拆解爆款、开始创作、我的内容、我的画像、模型设置六个主路由不变。
- 热点仍然来自公开榜单，选择热点仍然进入创作页。
- 画像仍然按版本保存，模型 API Key 仍然只通过现有配置流程处理。
- 本地草稿、服务端内容、未配置模型和后端错误继续按原状态展示，不把失败伪装成成功。

## 新视觉系统

- `DESIGN_VARIANCE: 7`：不对称热点网格、窄侧栏工具轨、阅读区和编辑区分层。
- `MOTION_INTENSITY: 4`：短促的 hover、focus、active 和首次进入动效，没有持续循环动画。
- `VISUAL_DENSITY: 4`：保留信息密度，但用结构线和留白代替重复卡片。
- 主色为石墨黑、烟熏绿、灰白文本，唯一强调色为酸橙色。
- 夜间为默认主题，顶部下拉支持跟随系统、夜间和日间。
- 圆角尺度固定为面板 14px、控件 8px、状态标记圆形或 8px，避免混用。

## 重点路径验收

- 热点页：刷新、来源筛选、搜索、写这个、空状态和骨架加载。
- 创作页：主题为必填，素材可选，平台和输出类型使用选择卡片，模型能力收进高级设置。
- 拆解页：平台选择、文本或链接输入、画像开关、错误恢复和结果编辑区。
- 内容库：服务端不可用时显示上下文错误，空库提供下一步动作。
- 画像：建议值使用 datalist，仍允许自定义填写。
- 模型设置：服务商、模型和 API Key 为主路径，高级地址和自定义服务商折叠。
