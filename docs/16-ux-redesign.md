范围：总览恢复快照 + 内容工作台输入恢复提示。大规模页面重排、真实浏览器验收和后续垂直切片仍未完成。

## 本次改动

- 总览增加进行中任务、待确认记忆、待核验来源、本地草稿和最近指标导入时间；增加“状态快照”区，显示本次读取时间和无数据限制。
- 新增 `GET /api/v1/overview`，从 SQLite 汇总任务、记忆、热点、草稿和指标导入计数；不调用外部连接器。
- 内容工作台新增输入草稿的本机 `localStorage` 自动保存（仅在尚未创建任务时），刷新后恢复标题、输入来源和素材；创建成功后清除恢复草稿。
- 工作台加载时从第一条输入恢复 `input_type`，避免 URL/会议记录被重新显示成主题。
- 简报编辑区显示来源数、事实数和“来源仍需人工核验”提示。

## 状态设计

| 状态 | 页面表现 | 可恢复动作 |
| --- | --- | --- |
| 加载 | 工作台显示“正在打开任务”和读取提示 | 失败后“重新读取” |
| 离线 | 应用壳显示服务离线和重试 | 启动本地后端、点击重试 |
| 脏状态 | 页面离开、平台切换、读取最新版本前确认 | 保存 revision 或保留表单 |
| 自动保存 | 新任务显示本机自动保存时间 | 刷新后恢复，创建后清除 |
| 来源缺失 | 简报显示来源数为 0、事实待核验 | 补 URL/文本/文件/热点后编辑简报 |
| 外部未配置 | 设置显示 `mock`/`not_configured`，不伪造登录 | 用户主动配置真实适配器（后续切片） |
